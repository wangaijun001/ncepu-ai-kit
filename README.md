## 🚀 快速开始（3 步）

1. **注册并拿密钥**：打开 http://202.204.64.234:8080 注册登录 →
   右上角**圆形头像** → **设置** → **账号** → **API 密钥** → **创建新安全密钥**
2. **填密钥**：把 `sk-` 开头的那串粘到 `api_key.txt` 的**第 1 行**，保存
3. **自检**：双击 `check-ncepu-ai.bat`，8 项能力全通过即可使用

然后打开 [完整接入指南](index.html)，找到你用的工具照着填参数。

> 需要 Python 3.9+ 才能跑自检脚本和反代；**只看文档不需要装任何东西**。

## ⚠️ 三条铁律（配置时最容易踩的坑）

```
1. Base URL 末尾不要加斜杠   → 加了会 405
2. Base URL 不要加 /v1        → 加了会 405
3. 模型名是 qwen3.8-27b       → 学校文档写的 qwen3-coder:30b 已不存在
```

唯一可用的接口地址：

```
POST http://202.204.64.234:8080/api/chat/completions
```

**如果某个工具报 405**：说明它会自己往地址后面拼 `/v1`，用本仓库的反代解决 ——
双击 `start-proxy.bat`，然后把工具里的 Base URL 改成 `http://127.0.0.1:8788/v1`。

## 🔧 模型能力速查

| 能力 | 支持 |
|---|---|
| 文本对话 / 流式输出 | ✅ |
| 工具调用（Agent 读写文件、执行命令） | ✅ |
| 图片输入（视觉） | ✅ |
| 思考模式 | ✅ 推理内容在 `reasoning` 字段 |
| 上下文 | 256K，但**输入 + 输出合计**不能超过 262144 |

**两个必须知道的限制：**

1. **思考强度只有 3 档真实可用**：`低` / `中` / `超高`。
   界面上若是「低/中/高/超高/极致」五档，**只勾前三个里对应的**，
   勾「高」或「极致」运行时会报 `400 Unexpected reasoning effort high`。
2. **输入 + 输出 ≤ 262144**：建议填**输入 128K + 输出 32K**，
   「256K 输入 + 64K 输出」会超限直接报错。

## 🔒 安全提醒

- **不要把真实 API 密钥提交到本仓库。**
  `api_key.txt` 里应始终是 `PASTE_YOUR_KEY_HERE` 占位符，你的密钥只填在自己电脑的副本里。
- 密钥与个人账号绑定，**不要共用、不要外传**。
- 所有对话内容都会发往学校服务器，**涉密 / 敏感内容不要输入**。
- 这是校内师生共用的服务，**别跑大规模批量推理**。
